# Smart-Dual-Authentication-Door-Security-System
RFID and password-based smart door security and access control system with automatic door closing and entry tracking.
Smart Dual Authentication Door Security System

Project Overview

This project is an individual embedded systems project that provides secure door access using RFID authentication and password-based authentication.

Users can unlock the door using either a valid RFID card or the correct password.

Key Features

- RFID-based authentication
- Password-based authentication
- Automatic door closing
- Entry time tracking
- Smart access control

Technologies Used

- Embedded Systems
- Arduino / ESP32
- RFID
- C/C++
- Wokwi Simulation

Working Principle

1. The user presents an RFID card or enters a password.
2. The system checks the authentication details.
3. If either method is valid, access is granted.
4. The door opens.
5. After entry, the door closes automatically.
